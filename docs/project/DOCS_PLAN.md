## 2. Principles

1. **One home per kind of document**, and the kind is visible from the path: project (stable), engine knowledge (measured), module design, mod review, data (tables the tools read or write), tests (evidence), archive.
2. **One source of truth per fact.** Rows and values: `ownership.csv` + the module sources. Engine rules: `engine/`. Status and open questions: one `STATUS.md`. Other documents link, they do not restate.
3. **Say how much to trust each file**: every document starts with a header block (section 4).
4. **Generated files say so and are never edited by hand**; a check regenerates them and fails on drift.
5. **Nothing is deleted.** Superseded or raw material moves to `archive/`, with a one-line reason, until you say otherwise.
6. **Docs sit with what they describe**: user-facing text for a mod stays in `modules/<id>/` (it goes into the archive that ships); design and evidence stay in `docs/`.

## 4. Conventions

- **Header block** on every Markdown file under `docs/`: `Status date`, `Kind` (project / engine / design / review / data / evidence), `Trust` (**measured** in game with the log named, **derived** from files, **reported** by a third party, **proposal**), and for engine and test files the **game version** (`1.9.6`, `1.9.8`).
- **Generated files** start with `GENERATED by tools/<script>: do not edit`.
- **Names**: lower-case with hyphens for prose (`ptf-rules.md`), upper-case only for the few anchors (`README`, `STATUS`, `ROADMAP`); no spaces; dates as `YYYY-MM-DD`.
- **Links** are relative and checked; a statement of a fact that lives elsewhere is a link, not a copy.
- **Version-sensitive statements** carry the version they were measured on (the manifest rule already changed between 1.9.6 and 1.9.8).
- **One change, one commit** for moves (`git mv` only, no edits), so history follows the files.

## 8. Risks

- Links and tool paths break silently: mitigated by `check_docs.py` and the one-commit-per-move rule.
- Splitting `PTF_FINDINGS.md` could lose the pointer from a finding to its log: each finding keeps its evidence column.
- Concurrent edits (another session wrote `new_mods_review/` while this one wrote `docs/mods/`): decide one place for incoming third-party material (`mods-review/raw/`) before step 4.
