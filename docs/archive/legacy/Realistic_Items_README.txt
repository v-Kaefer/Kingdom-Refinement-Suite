REALISTIC ITEMS - 1.1.5
This mod aims to bring more realism to game overall.


What's on this version?


Fatigue / Rest / Beds:

Now they actually matter!
Most of the sleeping spots received an upgrade that make them noticeable.
(It has more impact with the Fatigue changes)

* Sleeping Spots:
Received tweaks to be more relevant, since there are also tweaks with the Nourishment and Food systems.


Nourishment / Foods:

The nutrition and energy parameters are too insignificant so that they could reach a larger audience, but this breaks the relevance of this system, as well as others related to it, for anyone interested in the system.
This will bring actual relevance to it. Henry will feel hungry & sleepy more often, but not enough that it becomes a hindrance.

Now, the foods you eat, WILL BE IMPORTANT and you will have more of the RPG aspect of the game to care about. 
This could be a "make or break" for some players, if this is your case, stick with version 1.0.0. Another version can be provided upon request.

For example:
Most foods with higher durability ("processed/heavy food"), will lower your energy, therefore you will be tired sooner, with lower stamina and you'll have trouble staying awake.
Then, you'll also be able to see more of the "sleepy system"(as i'll call it), where it affects your vision and motor functions, making the game harder until you sleep.
But, foods with lower durability ("naturals/raws/dried") will give you more energy, but will be harder to manage! (More updates to come!)


Items:

* Reading books takes time!
Obviously, easier books take less time than harder ones. And the XP received has also been lowered, to match reading speed to a 1:1, as base values.



How To Install:

This mod edits a few .xml files.
If you have mod(s) that edits the same files, then you need to add the lines manually to that file you already use. This works on a new game and mid-game playthrough. This mod can be uninstalled or the lines removed at any time without any harm to your saves.

(RECOMMENDED)
Using Vortex app:

Just click on the Vortex button, at the top right corner of the mods header.
If you have any mod(s) that also alter/edit the rpg_param.xml file or any other that is also modded by this mod, Vortex app, will warn you about, and you will have to manually fix it.



Manual Method:

* If you DO NOT have any mod(s) that change the .xml files that are included in this modpack:

Download the file and with (preferably) 7Zip or WinRAR
Extract the KRS-Items.pak file to your "KingdomComeDeliverance\Data" folder
Play the game


* If you DO have mod(s) that change the .xml files:

1. Go to your "KingdomComeDeliverance\Data" folder and find the .pak file(s) that are from the mods
2. Open them up with 7-Zip or WinRAR and see if they contain the folders Libs > Tables > rpg > rpg_param.xml
3. Extract the rpg_param.xml file to somewhere and open it with a text editor of your choice like notepad
4. Save the file
5. Drag and drop the file back into the .pak file and overwrite if prompted
Play the game.


Uninstallation:

Manual Method:
Remove the "KRS-Items.pak" file or "Realistic Items" folder, from your "KingdomComeDeliverance\Mods" folder.
