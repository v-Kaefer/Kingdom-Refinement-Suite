# KRS Perks

Part of the Kingdom Refinement Suite. Brings back the Riposte perk and the Master Strike follow-up.

## What changes
- **Riposte** (perk `ec4c5274`) is visible in the perk list and unlocks at **level 10** (vanilla: hidden, level 5; the upstream restore mod used 8).
- **Master Strike (sword)** (perk `61e98757`) is visible.
- Perk names and descriptions for these perks are added for all 14 game languages (English text is used for languages the upstream mod did not translate).

Based on "Restore Riposte" by AcSiG (permission granted). Do not enable both mods: they patch the same rows, and the later mod wins.
If you keep both, load krs_perks after Riposte so level 10 applies.

## Install
Vortex: install `krs_perks-<version>.zip`. Manually: copy the `krs_perks` folder into `Mods/` and add `krs_perks` to `Mods/mod_order.txt`.
